# Project
Итоговый проект по курсу: Поиск мошеннических операций.
Данный скрипт на Python автоматически берет данные из файлов за разные дни (выписки по картам, терминалам и черные списки паспортов), загружает их в базу данных PostgreSQL, связывает с клиентами и ищет подозрительные операции.

# Содержание проекта 
main.py - главный файл,в нем написан код, который запускает весь процесс.
sql - папка с SQL-запросами (там создаются таблицы).
data - папка с исходными файлами (текстовые и эксель файлы за три дня).
archive - папка, куда скрипт переносит файлы после их успешной загрузки.
Задание - файлы, которые получены в качестве задания.

# Как запустить проект
Установить ( открыть ) PostgreSQL(DBeaver).
Создайте базу данных (CREATE DATABASE) postgres.
Создайте схему (CREATE SCHEMA) project.
Выполните скрипт ddl_dml.sql из папки Задание.(Для создания исходных таблиц, карт, счетов).

# Подготовка файлов и библиотек т запуск кода
Скачать проект на свой компьютер.
Открыть папку с проектом в VScode.
Создать файл .env в папке проекта и написать в нем свои логин и пароль от базы данных:
DATABASE_USER=postgres
DATABASE_PASSWORD=ваш_пароль_от_базы
Открыть терминал в VScode (Terminal - New Terminal).
Создать виртуальное окружение командой:
python -m venv venv
Активировать виртуальное окружение:
Для Windows: venv\Scripts\activate
Для Mac/Linux: source venv/bin/activate
Установить необходимые библиотеки командой:
pip install -r requirements.txt
Запустить скрипт командой в терминале:
python main.py

Код выведет в консоль список найденных мошенников ( не всех) и перенесет отработанные файлы в папку archive.
