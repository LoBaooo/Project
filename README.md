# Project
Итоговый проект по курсу: Поиск мошеннических операций.

Данный скрипт на Python автоматически берет данные из файлов за разные дни (выписки по картам, терминалам и черные списки паспортов), загружает их в базу данных PostgreSQL, связывает с клиентами и ищет подозрительные операции.

# Содержание проекта 
* main.py - главный файл, в нем написан код, который запускает весь процесс.
* sql - папка с SQL-запросами (там создаются таблицы).
* data - папка с исходными файлами (текстовые и эксель файлы за три дня).
* archive - папка, куда скрипт переносит файлы после их успешной загрузки.
* Задание - файлы, которые получены в качестве задания.

# Как запустить проект
1. Установить (открыть) PostgreSQL (DBeaver).
2. Создать базу данных `CREATE DATABASE postgres`.
3. Создать схему `CREATE SCHEMA project`.
4. Выполнить скрипт `ddl_dml.sql` из папки `Задание`. (Для создания исходных таблиц, карт, счетов).

# Подготовка файлов и библиотек и запуск кода
1. Скачать проект на свой компьютер.
2. Открыть папку с проектом в VScode.
3. Создать файл `.env` в папке проекта и написать в нем 2 строчки: `DATABASE_USER=postgres` и `DATABASE_PASSWORD=ваш_пароль_от_базы`
4. Открыть терминал в VScode (Terminal - New Terminal).
5. Создать виртуальное окружение командой: `python -m venv venv`
6. Активировать виртуальное окружение для Windows: `venv\Scripts\activate` (или для Mac: `source venv/bin/activate`)
7. Установить необходимые библиотеки командой: `pip install -r requirements.txt`
8. Запустить скрипт командой в терминале: `python main.py`

Код выведет в консоль список найденных мошенников (не всех) и перенесет отработанные файлы в папку archive.
